CI360 One Page WordPress Theme

Installation:
1. WordPress Dashboard > Appearance > Themes > Add New > Upload Theme.
2. Upload ci360-onepage-theme.zip.
3. Activate the theme.
4. Go to Appearance > Customize to edit Hero, About and Contact details.

Sections included:
- Hero
- About
- Services
- Team
- Contact
